# ZBK VR Mod

Implementation is not available yet.

## Responsibility

This repository will own optional client-side Fabric integration for the Zombies Build Kit VR experience, including Vivecraft-aware behavior where needed. The core datapack must remain usable without this mod.

## Dependencies

The planned integration targets Fabric and Vivecraft. Supported Minecraft, Fabric Loader, and Vivecraft versions, and any required resource-pack relationship, remain to be determined during migration. The mod is not a required dependency of the core datapack.

## Source and outputs

Mod source, build configuration, and the Gradle wrapper belong here. Publish distributable mod artifacts through the release process rather than committing build output. Build intermediates, caches, local client profiles, and settings are excluded.
